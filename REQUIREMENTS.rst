

REQUIREMENTS
~~~~~~~~~~~~

 - Apache 2
    
 - Asterisk 1.8 >=
    
 - MySQL 5.x or PostgreSQL 8.x
    
 - PHP 5 >= 5.6.0
    
 - PHP MODULES :
       * PHP-PGSQL or PHP-MYSQLi
       * PHP-MCRYPT
       * PHP_POSIX
       * PHP-GD
       * PHP-PCNTL
       * PHP-GETTEXT
       * PHP-SQLITE (only if you use the module to pool CDR)
       * PHP PEAR SOAP
